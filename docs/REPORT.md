# Отчёт: первая визуальная итерация (фазы 1–2)

## Что сделано
- **Форк движка.** Из Sakura Crossing взяты `toon`, `post`, `outline`, `util`, `player`,
  `sky`, `audio`, `hud` (MIT, авторство указано в README и в `LICENSE.sakura-crossing`).
  HUD и стартовое меню переведены на русский.
- **Палитра и грейд.** Тени сине-зелёные, свет тёплый бумажный, вечерняя дымка, виньетка.
- **Планета.** Радиус 150 м, трамвайное кольцо ~940 м по экватору. Трамвай сам тормозит у
  остановки, стоит 7 секунд и уезжает; `T` вызывает его к игроку.
- **Двор.** Девятиэтажка с аркой, кафелем и граффити («КИНО», «Лена + Дима»). Две хрущёвки
  буквой «Г». Площадка: ракета, лодочка (`E`), песочница с грибком, карусель (`E`), турник
  и шведская стенка. Выбивалка с ковром, 4 лавочки (у подъезда — пакет семечек), бельё,
  клумбы-шины с «лебедями», домино, мяч. 11 «ракушек» (одна приоткрыта), «семёрка»
  «баклажан», ещё 3 машины. 20 тополей, 3 клёна, кусты, столбы с провисающими проводами,
  тополиный пух вокруг камеры.
- **Ходьба.** WASD с коллизиями по AABB, ступеньки на крыльца и тротуары.

## Проверка
- `npm run build` проходит без ошибок.
- Консоль браузера чистая (`tools/shoot.mjs` собирает ошибки и предупреждения
  из headless-Chrome).
- Кадры в `docs/shots/`: `01-arch` (стартовый), `02-playground`, `03-garages`,
  `04-panel`, `05-tram`, `06-planet`.
- Производительность: headless Chrome, встроенная Intel UHD, 1600×900 с
  суперсэмплингом ×1.5 — 25–45 fps.

## Известные ограничения
- Подъезд № 3 пока закрыт: интерьера нет, кодовый замок не работает.
- Звуков нет (скрип качелей, звонок трамвая). Музыка не входит в поставку.
- Дальние дома — коробки с текстурными фасадами, вблизи это заметно.
- Контактный провод над двором не соединён с пантографом визуально идеально.
- Зон 4–5 из брифа ещё нет: ларьки, таксофон, теплотрасса, трансформаторная будка, садик.
